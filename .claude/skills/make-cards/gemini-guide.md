# 제미나이로 카드 사진 만들기

사용자가 **직접 찍은 제품 사진**을 제미나이(이미지 생성·편집)에 올리고, 아래 프롬프트로 캐러셀용 사진을 만든다.
만든 사진은 make-cards 1단계의 "사용자가 준 사진"으로 들어가고, 글자(톡 버블)는 `cards.py`가 얹는다.

## 원칙
- **글자는 제미나이에 맡기지 않는다.** 한글이 깨지고, 카피 규칙(copy-guide.md)·자동 축소를 못 쓴다 → 글자·말풍선 없는 사진만 받는다.
- **입력은 사용자 본인 사진만.** 레퍼런스 계정·타인 SNS·셀럽 사진을 넣지 않는다 (독창성 규칙·초상권).
  공식 제품컷은 "제품 모양 참고용"으로만 같이 넣을 수 있고, 결과물에 그대로 쓰지 않는다.
- **제품은 실물 그대로.** 색·로고·모양·소재를 바꾼 이미지는 실제와 다른 상품 광고가 된다 (표시광고 문제).
  뷰티 발색(립·블러셔·쿠션 호수)은 **색 보정 금지** — 배경·조명 정리만. 발색샷은 원본 사진을 우선 쓴다.
- AI로 만든 사진은 인스타가 'AI 정보' 라벨을 붙일 수 있다. 캡션 끝에 `일부 이미지는 AI로 편집했어요.` 한 줄을 넣는다.

## 1) 기본 설정 프롬프트 — 새 대화 처음에 한 번 붙여넣기

```
너는 인스타그램 패션·뷰티 카드뉴스 계정(@how.abouthis)의 사진 리터처야.
내가 올리는 사진은 내가 직접 찍은 실제 제품 사진이야. 앞으로 만드는 모든 이미지에 아래 규칙을 꼭 지켜줘.

1. 비율은 4:5 세로(1080x1350), 고해상도.
2. 제품은 내가 준 사진과 똑같이 유지해. 색상, 로고, 글자, 모양, 봉제선, 지퍼·버클, 소재 질감을 바꾸거나 새로 그리지 마.
3. 이미지 안에 글자, 말풍선, 스티커, 워터마크, 새 로고를 넣지 마. (글자는 내가 따로 얹을 거야)
4. 장면마다 내가 "비워 둬"라고 한 영역은 바닥·벽·천처럼 단순한 배경으로 남겨 둬. 글자가 들어갈 자리야. 그 영역에 제품 핵심이 걸치지 않게 해.
5. 실제 폰카메라로 찍은 일상 사진 톤. 자연광, 살짝 따뜻한 색감. 광고 CG 느낌, 과한 보정, 과한 배경 흐림은 금지.
6. 사람이 나오면 얼굴은 프레임 밖(목 아래)으로 잘라. 실존 연예인과 닮게 만들지 마.
7. 다른 브랜드 로고나 명품을 떠올리게 하는 소품은 넣지 마.
8. 이 대화에서 만드는 사진은 하나의 시리즈야. 색감·조명·배경 톤을 통일해.

이해했으면 "준비 완료"라고만 답해줘.
```

## ⭐ 제품 구조로 동작·상태 검증 (2026-10-05 사용자 지적 — 매번)
프롬프트를 다 쓴 뒤, 제품에 관한 **모든 동작·상태 묘사**를 실제 구조와 하나씩 대조한다. 안 되는 건 넣지 않는다.
- 먼저 구조를 적는다: 밑단·소매·카라 마감(립/시보리·스트링·오픈), 소재 두께·뻣뻣함, 핏, 여밈(지퍼·단추), 길이.
- 예: 밑단·소매가 **립(시보리)**이면 "밑단이 바람에 날림", "소매를 손바닥까지 끌어내림" 불가 → "밑단은 립으로 허리에 붙어 있음", "립 소매 끝을 손가락으로 살짝 잡음".
  두꺼운 데님은 "흐르듯 떨어짐"·"찰랑임" 불가. 지퍼 없는 옷에 "지퍼 고리 만지기" 불가.
- 자세끼리도 대조: 한 손이 주머니·가방끈에 있으면 "팔을 흔들며" 같은 묘사와 충돌.
- 바람·움직임은 머리카락·스커트·와이드 팬츠 같은 **제품이 아닌 것**에만 쓴다.

## 글자 자리 (cards.py 레이아웃 기준)
- **표지**: 아래쪽 45%에 제목·그라데이션, 왼쪽 위에 노란 태그, 오른쪽 위에 [광고] → 제품은 위쪽 55% 안에, 아래 45%는 비운다.
- **본문**: 말풍선을 `bubble: "top"`(위 120px~)에 둔다 — 레퍼런스도 본문 말풍선이 위쪽 가운데 → 위쪽 25%를 비운다.
- **마무리(CTA)**: 사진 전체가 어둡게 깔리고 가운데에 글자·댓글 입력창 → 제품 단독(플랫레이·컬러 라인업·진열) 컷이 기본.
  레퍼런스 마지막 장도 대부분 제품 단독 (2026-10-05). 본문용 제품 단독컷은 위쪽 25%를 비워 둔다.

## 레퍼런스 스타일 (2026-10-05 분석, 패션 상위 캐러셀 7개)
대상: @un_ni_item 몽벨(평소 대비 좋아요 ×19.5·댓글 ×23.6), GAP(×8.1·×8.6), 아디다스 도트 / @ssokssok.daily 아식스(댓글 ×10.5), 나이키(×6.9), 아디다스(×3.4), 오니츠카(×2.8).
조회수는 남의 계정이라 API로 못 받음 → 계정 평소 대비 좋아요·댓글 배수로 판단.
- **5장 고정**: 표지(착용·들고 있는 컷) → 본문 3장(각도·디테일·착용 바꿔가며) → 마지막 장은 **컬러 라인업**(매장 진열대, 여러 색 나란히) + 댓글 키워드.
- **폰카 UGC 톤**: 자연광, 살짝 따뜻하게. 스튜디오·연출 CG 없음. 아스팔트·콘크리트·원목 바닥·흰 이불·매장 선반 같은 생활 배경.
- **구도**: 거울 셀카(폰으로 얼굴 가림), 내려다보는 POV(발·손), 손으로 제품을 들어 보이는 클로즈업, 매장 진열 컷. 얼굴은 거의 안 나옴.
- **제품이 주인공**: 화면 40~60% 차지, 배경은 무채색이라 제품 색이 튐.
- **⭐ 표지는 제품 중심 (2026-10-05 검증, 패션·뷰티 표지 20개)**: 반응 상위 4개(몽벨 ×23.6·GAP ×8.6·나이키 ×6.9·립 ×3.8)가 전부 제품이 주인공.
  유형별 댓글 배수 중앙값 — 착용했지만 제품만 바짝 크롭(발·손·어깨) ×1.55 / 제품 단독·손에 든 컷 ×1.2 / 사람·전신 코디 중심 ×1.1(최고 ×1.7).
  → 표지는 **제품만 바짝 자른 착용 컷 또는 제품 단독 컷**. 전신 거울샷 같은 사람 중심 컷은 마지막 장(분위기)으로.
  (표본 20개·주로 2개 계정·댓글 배수 기준이라 경향으로 본다. 새 스캔 때 다시 확인)
- **⭐ 장 구성도 제품 중심 (2026-10-05 검증 + 사용자 결정)**: 패션 상위 7개 게시물 슬라이드 34장 = 제품 단독 ~16 / 바짝 크롭 착용 ~16 / 사람·전신 중심 2~3(그 게시물이 반응 최하).
  → 5장이면 **제품 단독 3장 + 바짝 크롭 착용 2장, 사람·전신 중심 0~1장**.
  제품 단독 장면 예: 옷걸이·행거, 소재·스티치 접사, 플랫레이, 코디 플랫레이(옷+신발+가방), 매장·박스 위, 손에 든 컷.
  바짝 크롭 착용 예: 가슴~무릎 크롭, 거울 셀카 크롭, 신발은 발만, 가방은 손·어깨만.
- **사람이 찍은 느낌** (거울·착용 컷, 프롬프트에 꼭 넣는다):
  - 거울 셀카: 폰을 얼굴 높이로 들어 얼굴을 가림, 폰 쥔 손가락에 반지, 어깨를 3/4쯤 돌려 옆선(삼선 등)을 보여줌, 가슴 위로 바짝 크롭하기도 함
  - 전신 거울: 바닥에 세워 벽에 기댄 전신거울, 얇은 거울 테두리가 보이고 살짝 위에서 비스듬히(3~5° 기울어짐), 바닥에 슬리퍼·신발 상자·다른 신발 같은 생활 소품
  - 자세: 한쪽 다리에 체중(골반 살짝), 발끝 살짝 안쪽, 한 발 앞으로, 빈손은 소매 끝·지퍼·가방끈·모자챙을 잡음. 두 명이면 서로 기대기
  - 야외: 낮은 턱에 한 발 올리기, 커피·미니선풍기 들기, 볼캡+땋은 머리로 얼굴 가림. 정면 차렷 자세·모델 포즈는 없음
  - 사진 자체: 완벽한 중앙 정렬 아님, 머리가 잘리기도 함, 옷 주름 자연스러움, 평범한 집(문·책장·옷걸이)
- **⭐ 한국 스타일 — 헤어·코디·배경은 [korean-style.md](korean-style.md)에서 고른다 (시즌별 조사 결과, 갱신 날짜 확인)**.
- **⭐ 한국 스타일 (2026-10-05 사용자 피드백 — 중요)**: 제미나이는 그냥 두면 코디가 서양·일반적으로 나오고 **헤어는 첨부 사진을 그대로 따라간다**.
  프롬프트에 반드시:
  - "첨부 사진에서는 제품만 가져오고, 헤어스타일·코디·배경은 따라하지 마"
  - 인물: 한국 20대 여성, 마른 체형. 헤어를 시리즈 전체에 하나로 지정 (예: 허리까지 오는 흑갈색 긴 생머리 + 시스루뱅 → 모자 장면은 같은 머리를 낮게 양갈래로 땋기)
  - 코디: 한국 인스타 패션 계정 꾸안꾸·여리여리 — 레이어드 튤·롱스커트, 벌룬·와이드 팬츠, 니삭스, 메리제인·발레리나 플랫, 볼캡, 나일론 숄더백. 시즌에 맞춰 고르고 장마다 바꾼다
  - 배경: 한국 원룸(흰 벽·원목 바닥·전신거울), 성수동 붉은 벽돌 골목, 아파트 단지 산책로. 간판 글자는 안 보이게
- **인형 키링**: 상위 2개(몽벨·GAP)가 모두 가방에 인형 키링을 달았음 → 코디 컷 소품으로 쓸 만함 (캐릭터 IP가 크게 보이지 않게).

## 2) 장면별 프롬프트 틀 — 사진을 올리면서 하나씩

| 장면 | 프롬프트 |
|---|---|
| 표지 | `첨부한 사진 속 [제품]이 주인공인 표지 사진을 만들어줘. [장면 설명]. 제품은 화면 위쪽 55% 안에서 크게, 아래쪽 45%는 비워 둬.` |
| 디테일 | `첨부한 사진 속 [제품]의 [부위: 로고·소재·지퍼·안감 등]을 손으로 들어 보이는 클로즈업으로 만들어줘. 질감이 선명하게, 배경은 [배경]. 위쪽 25%는 비워 둬.` |
| 착용·코디 | `첨부한 사진 속 [제품]을 입은 데일리룩 사진으로 만들어줘. [코디]. 얼굴은 프레임 밖, [장소]. 핏·기장은 원본 그대로. 위쪽 25%는 비워 둬.` |
| 수납·사용 | `첨부한 사진 속 [제품]에 [넣을 물건]이 들어간 모습을 위에서 내려다본 구도로 만들어줘. 물건 크기는 현실적으로. 위쪽 25%는 비워 둬.` |
| 발색 (뷰티) | `첨부한 사진의 색은 절대 바꾸지 말고, 배경만 [흰 천/베이지 종이]로 깔끔하게 정리하고 밝기만 자연스럽게 맞춰줘.` |
| 플랫레이 (본문 디테일) | `첨부한 사진 속 [제품]을 [장소]에 펼쳐 놓고 위에서 찍은 플랫레이로 만들어줘. 제품은 화면 아래쪽 75% 안에, 위쪽 25%는 바닥만 보이게 비워 둬.` |
| 마무리(CTA) | `첨부한 사진 속 [제품]을 입은 분위기 컷으로 만들어줘. [장소·포즈]. 가운데에 글자가 크게 얹히니 너무 복잡하지 않게.` |

착용 컷은 **사용자가 직접 입은 사진**을 넣고 배경·하의만 바꾸게 한다. 제품만 넣고 사람을 새로 그리게 하면 핏이 실물과 달라진다.

마음에 안 들면: `제품 모양이 원본과 달라졌어. 원본 사진의 제품을 그대로 쓰고 배경만 바꿔줘.` / `글자가 들어갔어. 글자 없이 다시.`

## 3) 받은 사진 검수 (make-cards에서 sheet.jpg로 확인)
- 원본 사진과 나란히 놓고 제품 색·로고·모양이 같은지 (다르면 버린다)
- 글자·워터마크·이상한 손가락·녹아내린 끈/지퍼 같은 AI 흔적
- 아래쪽에 말풍선 자리가 있는지, 4:5인지
- 표지 1 + 본문 3~6 + 마무리 1 = 5~8장

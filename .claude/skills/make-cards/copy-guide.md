# 이거 어때? 카피 가이드

계정 톤: 친구가 톡으로 "이거 어때?" 하고 보내주는 느낌. 반말 섞인 존댓말(~해요, ~잖아요, ㅠ, ㅋㅋ 가볍게).

## 표지 (cover)
- `eyebrow` (≤ 24자): 타깃 호출 또는 상황. "설거지 끝나고 수저통 뒤집는 사람 주목 👀"
- `line1` (≤ 10자): 문제/상황. `line2` (≤ 10자, 노란 형광펜): 반전·결과·질문.
- `sub` (≤ 26자): 제품이 뭔지 한 줄 + 이모지 1개.
- 후킹 공식 (하나 골라 변주):
  1. **상황 저격 + 해결**: "비 오는 날 신발장 / 냄새 끝내는 법"
  2. **질문형 도발**: "수저통에 고인 물 / 아직도 버려요?"
  3. **비포/애프터**: "자취방 싱크대가 / 이렇게 넓어진다고?"
  4. **숫자·구체성**: "설거지 10분 줄여준 / 3천원짜리 꿀템"
  5. **발견 서사**: "이거 하나 바꿨더니 / 주방이 달라짐 · "파우치 하나 바꿨더니 / 가방이 반으로 줄었어요"
- 출처·근거가 확인되지 않는 **"품절 대란", "N위", "연예인 OO가 쓴", "전문가 추천"은 쓰지 않는다** (표시광고법). 확인된 사실이면 출처 기억해두고 사용 가능.
- 효능 과장 금지: 의료·건강 효과, "100%", "완벽 차단" 등.
- 뷰티: 미백·주름·자외선 효과는 기능성 인증 제품만, "피부 재생"·"여드름 치료" 같은 의약품 표현 금지. "내 피부엔 이랬다"처럼 사용감으로 쓴다.

## 본문 슬라이드 (slides) — 3~6장
- 흐름: **공감(문제) → 핵심 원리 → 장점 1~2 → 디테일(사이즈·옵션·사용 장면)**
- `bold` (≤ 18자): 그 장의 한 줄 요약. 형광펜 밑줄이 들어감.
- `text` (≤ 26자): 구체 설명. 사진에 보이는 걸 설명할 것.
- 첫 본문 장은 공감형으로("~했잖아요 ㅠ", "~하는 거 저만 그래요?").

## CTA (마지막 장)
- 기본값 그대로 두면 됨: "그래서, 이거 어때요? 🤔 / 제품 정보 궁금하면 / 댓글 한 줄이면 끝" + 입력창에 키워드.
- `keyword`: 2~4글자, 제품을 떠올리게 (수저, 꽃게, 건조대). 다른 게시물과 겹치지 않게 history.json 확인.

## 캡션 (caption)
```
제품 정보는 댓글에 '<키워드>' 남겨주세요 📌

<표지 질문을 풀어 쓴 공감 한 줄> 🥲

✔️ <특징 1>
✔️ <특징 2>
✔️ <특징 3>

☝️ DM이 오지 않을 때는 요청함도 확인해주세요
🙌 프로필 링크로도 제품 확인할 수 있어요

이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

#<카테고리> #<제품> #<분야 태그> #꿀템 #<상황>
```
- 분야 태그: 살림·주방·인테리어 → `#살림템`, 뷰티 → `#뷰티템`, 패션 → `#패션템`.
- 해시태그 5개 내외. 광고 고지 문장은 제휴 링크를 쓰면 **항상** 포함 (카드에는 '광고' 표기가 자동으로 들어감).
- 첫 줄에 키워드 CTA (피드에서 '더 보기' 전에 보이게).

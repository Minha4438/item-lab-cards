# 리틀리 자동 댓글·DM 템플릿 (2026-10-05 사용자 확정)

게시가 끝나면 결과 보고에 아래를 **이 게시물에 맞게 채워서** 같이 보여준다. 사용자가 리틀리에 복사해 넣는다.
`{키워드}` = spec.json `keyword`, `{제품}` = 짧은 제품명(예: 데님 트랙탑), `{이모지}` = 제품을 떠올리는 이모지 1개(예: 👖).

## ① 공개 답글 (4개를 번갈아 — 같은 문구 반복은 스팸 판정 위험)
사용자가 확정한 문구. 1~3번은 그대로, 4번만 제품에 맞게 바꾼다.

```
DM 보내드렸어요! 📩 안 보이면 요청함도 확인해주세요 🙌
```
```
정보 DM으로 쏙 보냈어요 💌 요청함도 한 번 봐주세요!
```
```
보내드렸어요 🤍 DM 확인해보세요!
```
```
{제품} 정보 DM으로 갔어요 {이모지} 요청함도 체크!
```

## ② DM 메시지
```
안녕하세요! 이거 어때?예요 🙌
궁금해하신 {제품 정식 이름} 정보예요 {이모지}

👉 [쿠팡 링크]

✔️ {카드·캡션에서 확인된 특징 1}
✔️ {특징 2}
✔️ 구매 전에 사이즈·컬러 옵션 꼭 확인해주세요!

이 링크는 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.
```
- 파트너스 고지 문장은 **절대 빼지 않는다** (링크를 직접 보내는 메시지).
- 특징은 캡션 ✔️ 중 확인된 것만. "최저가·품절 임박·1위"처럼 확인 안 된 표현 금지.

## ③ 팔로우 전이라 DM이 안 갈 때 (리틀리에서 팔로우 조건을 켰을 때)
```
DM 보내드리려고 했는데 아직 팔로우 전이라 전송이 안 돼요 🥲
팔로우 후 댓글에 '{키워드}' 한 번 더 남겨주시면 바로 보내드릴게요!
```
